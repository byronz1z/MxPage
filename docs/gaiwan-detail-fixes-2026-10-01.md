# 盖碗测试反馈修复记录

对应用户报告的三类问题：详情页上下衔接、推理说明进入成品文案、缺少品类必需内容。

## 相邻成品参考

原 V3 流程只发送相邻图片最外侧 2% 的色带，没有完整的前页构图和光线信息。现在保留原始商品图，并同时发送上一张详情的当前完整成品及底部色带；修改中间页时也发送已存在的下一张完整图及顶部色带。

各参考图分别标记身份用途：原商品图用于 SKU 保真，相邻成品用于衔接，外部风格图用于设计。相邻成品不能充当商品事实来源，也不能让模型复制它的标题、物体布局。

实际相邻图片的边缘颜色、明暗、纹理优先于计划中的 HEX 色值。生成与检查采用同一优先级，避免模型仍按计划色生成、忽略上一张实际成品。顺序生成、保存版本、每图最多一次自动修正的原有机制保持兼容。

## 成品文案与内部拍摄任务分开

核对了用户测试项目 `cmuowensx002pjdukoknmvdjz` 的保存数据，真实文案包含“手边的相对尺度”“从上方看圆形盖面”“侧面看清上下轮廓”“泡茶三盖碗，回看外观”。这些具体案例已加入测试。

内部 task、camera、production 字段仍可描述拍摄方法；AI 生成的 textBlocks 如果包含此类视角、尺度参照、外观回看等推理说明，会在出图前被拦截，要求重写为面向买家的文案或合理的无字画面。复核提示词同时检查这类问题。用户明确要求原样保留的文字仍遵循原样要求。

## 品类内容和最后一页

新 V3 规划必须提交结构化 productInformation，包括参数标签、值、依据 ID 和可选尺码表；每页标明 general、on_body 或 specifications 内容职责。默认最后一张详情必须是规格参数信息页，导演与局部复核不能把它改成纯摄影或外观总结。

| 品类 | 内容要求与参数方向 |
| --- | --- |
| 三才碗、陶瓷器具 | 真实部件与适当使用情境；末页整理已知名称、材质、容量、口径/高度、组成与养护资料 |
| 服饰、鞋包 | 至少一张真实上身/穿戴任务；末页参数，并保留已提供的尺码、测量值和单位 |
| 数码、家电 | 使用情境、可见接口/控制；型号、规格、尺寸、兼容和真实包装清单 |
| 食品、美妆 | 适当使用/食用情境；已知成分、净含量、储存/使用与有效期资料 |
| 家居、家具 | 空间安放与人体关系；已知尺寸、材料、组成和护理 |
| 图书 | 书封、装帧或已提供的内页；已知版本、开本、页数和出版信息 |

以上字段按资料选择，不是要求模型补齐未知数字。关键尺寸/容量或服装尺码资料不足时，提示词要求使用现有的一次性补问流程；用户跳过后，只展示已知参数，不生成空表、“待确认”或猜测的 S/M/L 数值。明确要求不要规格页或全套纯摄影的用户指令可以覆盖默认收尾规则，且必须有真实指令来源。

参数与尺码信息会继续传入导演和复核，不再在裁剪规划上下文时丢失。编译器输出明确的参数表及尺码行列关系；校验保留实际数值，避免“100”因包含在“1100”中而误判为正确。
