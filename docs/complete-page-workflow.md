# 完整出图、多角度与局部审查

更新日期：2026-09-29。本次按用户新要求取消“首图质量不通过就停止整套”的旧行为；用户主动停止、服务中断、缺少有效方案和厂商错误仍如实处理。

## 内容规划依据

[Shopify 产品页实践](https://www.shopify.com/blog/product-page)将商品呈现、描述、选购信息和使用情境结合；[Shopify 产品页优化](https://www.shopify.com/blog/expert-advice-improve-product-pages)还涉及规格、材料、使用说明等内容。[Amazon A+ 内容设计指南](https://sell.amazon.com/blog/a-plus-content-design-guide)提供图文、规格、对照、品牌故事和问答模块。[Amazon 产品摄影指南](https://sell.amazon.com/blog/product-photos)讨论不同角度和生活方式摄影。

实现中的 11 类内容任务：定位、卖点、依据、场景、细节、选购、规格、使用、清单、答疑、品牌故事。它们是按证据选择和合并的内容库，并非要求每件商品都生造 11 屏。四屏详情合并为定位与价值、细节依据、情境使用、选购档案；数量较多时展开有依据的独立利益点。品类规则继续分别覆盖图书文创、数码、家电、食品、美妆、服饰、家居和日用品。

价格、购物按钮、真实评价、物流与售后属于平台界面信息。生成图片不伪造这些数据，也不将 Amazon 平台的格式建议误称为淘宝强制规则。

## 执行行为

1. 规划保存固定数量与固定图片 ID，每屏保留买家问题、任务、事实来源。
2. 视觉导演提交完整分镜。程序检查 ID、必填结构、排版、接缝和镜头多样性；格式修正最多一次。美学多样性建议在一次调整后仍未解决，记录提醒，不终止整套。图片 ID 缺失/重复、字段不合法、接缝关系错误仍需补齐，否则无法正确执行。
3. 审查器不能重新提交整套分镜。它只提交具体问题与字段级 `before/after` 替换。程序拒绝空替换、未知图片、修改未指出问题的图片、重复修改同一字段、错误原文或不存在的事实依据。事实问题必须为受影响的每屏提供有依据的替代内容。
4. 原始设计草稿、具体替换和检查说明分别保存在 JSON 检查点。文案同时写入页面模块、最终提示词与图片版本；原买家问题不再被视觉描述覆盖。
5. 各图片按固定顺序执行。首图仍先检查并最多修正一次，但质量失败只标记“需检查”，不再停止其他图。未通过首图不作为后续风格参照。
6. 单图审查接口异常时保存图片，继续其他图；没有审查结论不会触发收费修正。继续任务时仅补审已保存图片。
7. 图像请求结果不确定时不自动重试、不冒充成功，保留图片位置并继续其他图。用户可以继续其他任务，也可明确勾选重试该请求。取消、恢复与重复点击仍保留已生成图片和修正次数。
8. 整套检查仅记录结果，不再追加收费出图。全部生成但有质量/检查问题仍标为部分完成，文案显示“已生成全部图片，部分需检查”，避免把数量完成等同于质量通过。

## 多角度和上下衔接

新分镜 `viewVersion: 1` 逐图记录 `viewpoint` 和具体镜头；检查整套至少三种机位，头图和详情各至少两种（该组至少三张时）。允许正面、真正的三分之四视角、侧面、俯视、特写等，不再将斜侧视角统一限制成微小正面偏转。商品身份与可见结构保持；没有依据时不凭空加端口、后印花、开关、内构或配件。

文字编排与相邻详情接缝继续使用上一轮规则：每屏独立字形/层级/装饰方案，每个详情切口共享一个明确颜色，生成和检查都参考真实相邻图片。历史任务仍读取原分镜；没有自动重做旧图。

## 验证

命令：`npx tsc --noEmit`；`npx tsx --test tests/*.test.ts tests/*.test.tsx`。本轮完整回归通过 **74 项**，日志：`ui-review/complete-page-tests.log`。

- 全部七图被质量审查拒绝：仍保存七图，最多十四次模拟图像请求；再次继续不会重新出图。
- 首图请求不确定：其余六图完成，重复继续不重试；明确重试后仅补该图。
- 审查器事实修正：只替换目标文本，其他六屏及图片数量不变，页面、提示词、版本文案一致。
- 七张图的审查接口全部失败：七图保存，不进行自动修图；恢复检查不新增图像请求。
- 首图版本切换、手动编辑后恢复、失效租约、重复启动、批量隔离、翻译、小红书、ZIP/长图/JSON 回归均覆盖。
- 旧 SALONIA 项目浏览器兼容检查：七图和手机预览正常加载，仍可下载长图；不确定请求的“继续其余图片”按钮可用。未点击任何收费生成操作。

使用本地模拟 Provider 和独立临时数据库。测试验证执行行为与数据一致性，不证明真实模型必然生成美观、无错字的图片。厂商出图失败、鉴权失败或结果不确定仍可能造成缺图，界面会保留对应位置与错误，不假报完整成功。
