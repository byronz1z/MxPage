# 详情页多语种翻译

入口：详情页翻译（`/translate`）。单张、多张和文件夹提交后立即跳转独立进度与预览页（`/translate/[batchId]`），上传期间也显示进度；旧批次链接自动跳转。

浏览器草稿 v2 将原图与上传进度拆分保存：原图仅首次写入，后续断点和重试只更新项目标识及已上传张数。旧版草稿在恢复时原子迁移，成功后才移除旧记录；提交成功或移除草稿时一并清理原图与断点。旧标签页阻止数据库升级时提示关闭旧页再重试，不丢弃草稿。

作品卡片加载独立 WebP 缩略图（最长 640×960 范围内等比缩小，不放大小图），缓存可重建，最多同时编码两张。同源并发请求复用一次生成，源文件变化后重新生成；原图对照、结果页及导出仍使用原始图片。缓存位于素材目录 `.thumbnails`，不写入素材或版本记录，也不需要随备份保存。

作品列表按作品类型选择入口，翻译草稿不会进入详情页配置；旧配置链接会导回翻译进度或结果页。上传前使用 IndexedDB 保存原图、参数及上传断点，刷新后先检查服务端批次：已提交则只恢复进度，未提交则续传。项目和单图上传使用固定标识，响应丢失后的重试复用已有记录，且同一标识不能换成不同内容。服务端接收批次后清除本地原图草稿；API Key 不进入草稿。浏览器禁用存储或空间不足时会暂停上传，清除浏览器站点数据会失去未提交的本地草稿。

- 单张：一张原图；多张：最多 30 张组成一套，按文件名自然排序。
- 文件夹批量：根目录每张图片单独一套，一级子目录及其下层图片为同一套；最多 50 套，每套 30 张，单图 10MB。选择后先预览分组。
- 一次可多选现有十种语言，UI 展示原图张数 × 语言数的预计输出数量。
- 新上传的每套图片、每种语言只保存一个结果项目，不额外保留原图项目：第一种语言直接使用上传项目及原图，其余语言独立复制原图。每种语言始终直接从原图翻译，不串联翻译。旧批次仍按原有项目关系恢复，不修改或删除历史作品。结果可原图/译图对照、长页预览、下载对应语言 ZIP 和完整长图。

后台批次队列只负责分发任务，翻译执行器位于 `lib/translation/service.ts`，逐图进度保存在独立的 `TRANSLATE_PAGE` 任务中。不会创建或执行 DetailRun，不调用分析、规划、视觉检查模型。

固定提示词位于 `lib/translation/prompt.ts`。每次仅发送一张原图、目标语言及可选术语要求，调用一次图像编辑接口，保留商品、背景、版式、数字、单位和表格。编辑器中的单图翻译也复用此提示词，跳过视觉提示词 Agent 和 SVG 兜底。

每套最多并发 2 张，每张完成即保存图片与版本。失败不自动改模型、重绘或重试。停止批次后保存已经发出的请求结果，不再开始下一张；继续只处理未开始的图片。超时和中断请求标为结果不确定，只有点击“重试失败图片”才再次发送；成功图片不重复请求。旧翻译批次可由批次页继续，失败的旧分析步骤不会重新执行。

向图像 Provider 使用 `size=auto`，提示保持源构图和比例；实际输出尺寸依模型支持，无法保证逐像素不变。模糊文字与翻译质量仍需核对。

翻译进度、逐图失败原因与操作都在批次页面展示；结果尚未生成时，原图不会被当成完成结果或放进结果导出。

结果页有进行中的任务时持续同步，完成后停止定时轮询；切回页面时同步一次，如果发现新的运行任务则恢复轮询。隐藏页面暂停请求，全局队列空闲时每 30 秒检查其他任务。作品列表和项目列表的封面使用按页面顺序找到的第一张当前选中结果图，不使用未选中的历史版本；没有结果时回退原图。封面选择只改变读取展示，不改动原图、版本或已有数据。

旧流程中已有关联结果的纯翻译原图项目，从作品列表及分类计数中隐藏。仅排除标记为翻译、没有页面、任务或生成/导出素材的原图项目；不删除项目记录或文件，原图对照和批次恢复仍可读取。新上传中的项目、直接成为翻译结果的项目及有独立创作内容的项目仍显示。若关联结果不再存在，保留的原图项目会重新显示。

验证：`tests/translation.test.ts` 使用隔离 SQLite、临时文件和模拟图像接口，覆盖多语言批量、并发上限、原图独立保存、ZIP/长图导出、停止恢复、超时、手动重试、编辑器单图翻译、旧 PLAN 失败批次恢复以及独立结果页渲染。测试中只配置图像编辑模型，任何分析或聊天接口调用均会失败。浏览器已验证翻译入口及多语言选择；本次未调用真实付费模型验证译文质量。
