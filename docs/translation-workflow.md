# 详情页多语种翻译

入口：详情页翻译（`/translate`）。结果项目使用独立的翻译预览页。

- 单张：一张原图；多张：最多 30 张组成一套，按文件名自然排序。
- 文件夹批量：根目录每张图片单独一套，一级子目录及其下层图片为同一套；最多 50 套，每套 30 张，单图 10MB。选择后先预览分组。
- 一次可多选现有十种语言，UI 展示原图张数 × 语言数的预计输出数量。
- 每套、每种语言建立独立结果项目和文件副本。每种语言始终直接从原图翻译，不串联翻译，不覆盖源项目。结果可原图/译图对照、长页预览、下载对应语言 ZIP 和完整长图。

后台批次队列只负责分发任务，翻译执行器位于 `lib/translation/service.ts`，逐图进度保存在独立的 `TRANSLATE_PAGE` 任务中。不会创建或执行 DetailRun，不调用分析、规划、视觉检查模型。

固定提示词位于 `lib/translation/prompt.ts`。每次仅发送一张原图、目标语言及可选术语要求，调用一次图像编辑接口，保留商品、背景、版式、数字、单位和表格。编辑器中的单图翻译也复用此提示词，跳过视觉提示词 Agent 和 SVG 兜底。

每套最多并发 2 张，每张完成即保存图片与版本。失败不自动改模型、重绘或重试。停止批次后保存已经发出的请求结果，不再开始下一张；继续只处理未开始的图片。超时和中断请求标为结果不确定，只有点击“重试失败图片”才再次发送；成功图片不重复请求。旧翻译批次可由批次页继续，失败的旧分析步骤不会重新执行。

向图像 Provider 使用 `size=auto`，提示保持源构图和比例；实际输出尺寸依模型支持，无法保证逐像素不变。模糊文字与翻译质量仍需核对。

翻译进度、逐图失败原因与操作都在批次页面展示；结果尚未生成时，原图不会被当成完成结果或放进结果导出。

验证：`tests/translation.test.ts` 使用隔离 SQLite、临时文件和模拟图像接口，覆盖多语言批量、并发上限、原图独立保存、ZIP/长图导出、停止恢复、超时、手动重试、编辑器单图翻译、旧 PLAN 失败批次恢复以及独立结果页渲染。测试中只配置图像编辑模型，任何分析或聊天接口调用均会失败。浏览器已验证翻译入口及多语言选择；本次未调用真实付费模型验证译文质量。
