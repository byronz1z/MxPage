# 头图与详情页生成质量 V2：实现与验收

日期：2026-09-29。代码验证通过；首轮真实视觉验收未通过，按首图放行规则提前停止。

## 已实现

- 商品事实、AI 推荐方向、用户自定义要求分开保存。商品复核不再返回或改写布景、构图等设计字段；自动预填不会成为用户强制要求。
- 新增图书／文创规则。内容规划提供事实和任务，视觉导演可改写任务、标题及消费者文案；单独复核最终方案的事实与语义重复，最多返修一次，未定稿不出图。
- 定稿同时写入运行方案、页面模块、分镜和版本快照；实际提示词只渲染定稿文字。
- 11 张用户提供案例整理为本地参考图片与分类目录；多列长页裁成单屏。每套最多两张参考，用户上传优先，按商品类别补齐内置参考。图片实际参与视觉导演、图像生成和视觉检查。
- 商品与风格素材分用途，旧素材默认商品素材。风格素材不参与识别、商品数量或翻译源图；并发上传数量限制在服务端串行校验。
- V2 每张图片编译为单份具体创意简报；11 套文字方案仅供设计导演借鉴。原图约束商品身份，允许重新设计布景、光线、构图和版式。
- 首图通过且验收记录匹配当前生效图片版本，才能生成后续图片。首图最多自动修正一次；仍失败或请求不确定就暂停该商品。后续逐图对照已有图片，整套检查不追加收费生成。
- 恢复、手动修改和版本切换会重新核对首图记录，不重复生成已有图片，也不重置自动修正次数。结果不确定必须明确重试。
- 单商品和批量共用流程。批量中一件商品暂停后继续下一件。
- 第二步与批量配置提供折叠的风格参考上传区；工作台展示首图验收状态、具体原因、实际参考图片、主题和逐图任务。
- 仅新任务采用 V2；历史任务保留检查点。没有新增服务、队列或数据库字段。小红书、翻译、导出与手机预览保留原流程。

## 模型判定（与人工观察分开）

首次生成后，模型认为石面及硬直角背景偏离本张具体简报，要求修正背景。修正一次后仍判定不通过：

1. 标题在 375px 宽下约 24px，低于本次简报的字号目标。
2. 主体仍居中，右下错位构图执行不足。

以上字号及构图描述是模型判断，不是像素测量或客观美学评分。最终状态是 `PARTIAL / 首图需调整`；两次图像请求，两个历史版本，一次自动修正，后续六张全部保持未请求。没有继续收费生成。
