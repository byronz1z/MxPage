# V3 创作流程实现与验证

日期：2026-10-01。仅新建电商详情页任务使用 V3，已有 V1/V2 检查点沿原流程继续。

## 执行路径

事实/素材 → 内容任务（无逐图文案）→ 视觉导演选择表达方式 → 文案与分镜审查 → 按位置生成并检查 → 有限后续改稿 → 整套检查。

官方 Agents SDK 承担理解、规划、视觉设计及审查；程序负责数量、调用顺序、幂等、修改资格、事务和导出。批量复用同一服务。

- `photo`：无新增文字，`textBlocks=[]`、`typography=null`、`graphicDevice=null`；保留商品印字。
- `annotation`：局部有依据的标注。
- `statement`：有信息价值的主张。
- `information`：已知参数、步骤、选购信息。
- 不设置有字/无字比例；全局主题统一，具体镜头、比例、空间、阅读路径由导演选择。
- 内容规划只提交事实、购买疑问、任务、事实来源与显式用户要求。兼容字段在内部暂存为空，不传回导演造成文案锚定。
- 审查可替换受影响的完整分镜，删除或合并 AI 文案。程序检查所有图片位置、显式要求及用户原文仍存在；事实依据和语义覆盖由视觉审查判断。
- 最终方案、模块文案、提示词、图片版本同步保存；纯摄影的字体检查必须返回“不适用”。

## 参考和连续长页

逐图记录参考 ID 和 photography / palette / layout 用途。纯摄影不接收排版用途参考；新流程不自动传入完整首张头图。详情图片生成只接收相邻图片末端 2% 的边缘像素及共享 HEX 色值。审查仍可查看完整邻图来判断真实接缝。

内置案例增加表达适用标签。参考中的商品、品牌、价格、认证及文字均不得转为当前商品事实。提示词按表达方式编译，避免平台通用指导重新插入标题规则。

设计参考依据：[OpenAI 图像提示词指南](https://developers.openai.com/api/docs/guides/image-prompting)。采用清晰的参考角色、当前画面所需指令和对实际成品的检查；该指南不构成成品质量保证。

## 有限动态改稿

两个机会：前两张头图后、前两张详情后。复用逐图检查的 distinctness/重复问题，只有发现重复且仍有可修改位置才调用导演，每个机会最多一次。

调用前持久化 claimed。重启遇到 claimed 会标记中断并保留原方案，不重复请求。只能修改从未请求、没有图片、没有 attemptKey、没有重试标记、修正次数为零的位置。事务内再次检查运行租约和模块状态，同时写入新分镜、文案、提示词、项目快照与检查点。错误保留旧方案继续；取消不提交改稿。已出图位置和修正次数不变。

## 自动化覆盖

- 无字提示词、原包装印字、字体不适用、冗余文案删除、显式用户文案保护、完整位置。
- 不同构图名称不能掩盖相同空间描述；实际成品的重复仍由视觉模型判断。
- 风格素材隔离、按图参考、真实末端 2% 图片输入、共享接缝。
- 改稿两次上限、只改未请求位置、原子同步、改稿故障降级、取消与重复继续。
- 充电器、服饰、香氛、图书、食品的合同示例。此类模拟数据验证契约，不代表真实跨品类视觉质量已通过。
- 历史提示词、批量、翻译、小红书、版本、JSON、ZIP、长图兼容。

自动化日志：`ui-review/creative-v3-all-tests-final.log`（含真实验收发现后的补充用例）、最终集成日志 `ui-review/creative-v3-integration-final.log`。
TypeScript：`npx tsc --noEmit`。
