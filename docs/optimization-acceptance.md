# 稳定性、能力提示与预算优化（2026-10-19）

本轮只使用临时数据库、独立存储和模拟上游。用户明确要求不调用真实服务；没有使用账号额度。下列“通过”不代表任何具体服务账号、模型或桌面系统的真实验收。

## 任务结果与恢复

- 任务队列和耗时记录区分“已失败”“结果未确认”“待查询上游结果”，不再把所有未确认图片计入失败数。执行中的请求仍显示处理中。
- 新单图、重新生成、编辑、单图翻译、小红书图片操作在提交前保存恢复信息，取得异步任务编号后立即落盘。任务列表提供“查询原结果（不重新生成）”。仅查询已有 EvoLink 任务，不重新规划、上传参考图或 POST 生图。
- 恢复读取原服务、模型和协议快照。查询所有权防止重复执行；下载好的图片可复用，版本和任务完成记录通过同一事务提交。迟到结果不会覆盖用户已切换的新图片；停止后的结果仍可保存为历史版本。
- 小红书图片保存到本地，批次继续复用已完成页面。已有未确认子请求时不再提交该页；先在任务记录中查询子请求。
- 没有上游编号的超时/断流不能自动取回结果。历史记录缺少恢复描述时也不能凭空重建，只展示待核对状态；不会批量改写旧任务或静默重发。
- V4 和批量翻译继续使用各自原有恢复入口与计费约束。Agent 金额预算在发出请求前拦截时，V4 标记为本地拒绝而非已发送的未知请求。

## 能力界面

- API 设置页、详情页配置及批量创作/翻译使用已保存模型的能力投影，无需手选协议，也不发起图片探测。
- 文档明确的参数约束用于限制画质、背景、格式、尺寸、压缩和审核选项，并展示参考图上限与蒙版支持情况。未知接口保留兼容选项，标记能力待确认。
- “参数依据接口文档”和“此服务曾成功返回图片”是两条独立证据。一次成功调用只证明该次路径可用，不等于验证了所有参数、编辑方式和账号权限。成功路由缓存新增时间戳。
- 前端不能替代适配器的参数检查；已有任务的参数和协议快照不改变。

## 费用预算

在 Agent 设置中可选填任务金额预算（USD），另设单次请求预留值；留空保持原行为，0 阻止启动新任务。原模型/工具调用次数上限继续生效。

模型、搜索和 MCP 请求在分派前以事务预留额度，并发任务共享同一账本。接口返回金额优先，其次按已有计费规则估算；无法计价时保留原预留额，并可要求用户核对后才继续。界面分别展示接口金额、估算、在途预留、未知费用和总占用。暂停后可以明确追加金额；追加次数预算不会暗中追加金额预算。已发出的请求允许收尾，新的所有者不能写入旧请求结果。

这是基于预留值和可得用量的本地预算保护，**不是服务商硬扣费上限**。单次实际费用可能超过预留值，未知价格、异步任务及第三方工具可能无法核算。连接能力验证发生在任务建立前，可能另计费；本轮测试没有执行任何真实验证。

## 性能与工程检查

- 读取最近 N 条监控记录改为文件尾部分块读取；缓存命中时图像适配不再读取历史日志。全时间窗口统计仍读取完整记录，以保留统计准确性。
- 详情页和任务历史页在隐藏时停止轮询；恢复可见时重新同步，空闲时降为 30 秒。活动任务保留短间隔更新；不会因重连重发写请求。
- `npm run lint` 不再空成功，执行 TypeScript 类型、switch 穿透、不可达代码和无效标签检查。它是静态代码检查，不宣称覆盖完整 ESLint 风格规则。
- 业务回归 CI 配置覆盖 Ubuntu、Windows x64、macOS ARM64/x64，使用 [GitHub 标准运行器](https://docs.github.com/en/actions/reference/runners/github-hosted-runners)。这里只增加配置，不代表云端矩阵已执行。
- 没有新增依赖、数据库迁移或协议选择开关。
