# MxPage v0.3.1

2026-10-20。详情页生成前统一确认提示词，并清理已退出使用的旧界面。

## 生成前统一确认

- 新建单商品与批量详情任务在分镜完成后暂停。全部主图和详情图的完整提示词在同一页展开，可连续编辑、统一保存和确认。
- 保存草稿不发送模型请求；确认后才开始生图。实际请求使用用户确认的内容，质量检查同步参考修改后的构图与文案。
- 已保存修改在刷新、停止和继续后保留。版本检查防止旧页面覆盖新修改，同一确认重复提交不重复派发生图。
- 任务队列和批量作品提供提示词确认入口。历史任务、小红书和独立翻译保留原有流程。

## 源码清理

- 删除 10 个无运行入口的旧组件，约 4,200 行：旧商品分析、规划、编辑、创建、导出、小红书工作台及其专用辅助组件。
- 删除范围经过 TypeScript 模块引用扫描和文本引用核对。保留旧地址跳转、历史数据读取、任务恢复和仍在使用的服务/API；调整静态测试，保留服务端回归检查。
- MCP 客户端版本改为读取应用版本，避免安装包升级后仍报告旧版本。

## 桌面下载与升级

| 平台 | 文件 |
| --- | --- |
| Windows x64 | `MxPage-0.3.1-windows-x64.zip` |
| macOS Apple Silicon | `MxPage-0.3.1-macos-arm64.zip` |
| macOS Intel | `MxPage-0.3.1-macos-x64.zip` |

完整解压到新目录后启动；macOS 可将应用移到“应用程序”。升级前建议在“设置 → 数据管理”创建备份。此版本不新增数据库迁移，不改写已有任务。

构建流水线在三个对应系统上打包，使用 Electron 自带运行时验证空数据库迁移、Prisma/sharp 原生模块及主要 HTTP 页面。全部通过后发布 ZIP 和 `SHA256SUMS.txt`。这不等同于桌面 Agent 对第三方软件的真实 GUI 操作验收；该能力仍按原有权限和验收状态开放。无商业代码签名或 Apple 公证。

## 验证范围

自动验证使用临时数据库、独立文件目录和模拟上游，涵盖保存失败、刷新恢复、版本冲突、重复确认、桌面/手机布局，以及确认后生成、检查、预览和下载的端到端流程。不调用真实付费模型。

此前 v0.3.0 发布后的协议兼容和真实接口验收记录见 [v0.3.0 源码更新记录](v0.3.0.md)与[服务实测记录](../provider-live-acceptance.md)。
