# MxPage v0.3.2

2026-10-20。更新小红书图文排版与结果画廊，并同步 Windows 和 macOS 桌面包。

## 小红书图文

- 修复小红书数量解析：支持“张”和“页”，不再把“第一张”“最后一张”等位置描述误判为总数量冲突。保留 1–8 张边界及真正冲突数量的拦截，校验发生在付费请求之前。
- 小红书启动或操作失败时，页面持续显示原因，成功的进度轮询不再让操作错误消失。修正问题后继续同一个项目。
- 小红书新任务使用独立规划与视觉分镜规则，内置五类排版风格，约束文字密度、信息层级、安全边距和逐页构图。统一视觉母版进入每张实际生图提示词，尊重用户指定风格；不增加模型调用步骤。规则随新任务保存，旧任务恢复不被新规则改写。
- 小红书结果区改为缩略图总览和大图画廊：支持上下页、方向键、缩略图跳页、原尺寸查看、单张下载及整组 ZIP。保留未生成页面位置，检查提醒匹配当前图片版本，关闭画廊后恢复键盘焦点。
- 验证范围：84 项模拟回归与类型检查通过，浏览器复用已有 8 张图片验收画廊；另经用户授权，以 Flare 实际生成 4 页新版图文，验证新版规则快照、真实生图、文案与 ZIP 导出。整套检查通过，第 3 页底部说明保留字号警告；人工复核发现封面漏一处小标签及一页使用简化人形符号，未自动付费重画。细节见[真实验收记录](https://github.com/ziguishian/MxPage/blob/v0.3.2/docs/provider-live-acceptance.md)。
- 移除根目录中已不适用的 nanobanana-mall 使用教程文档。

## 桌面下载与升级

| 平台 | 文件 |
| --- | --- |
| Windows x64 | `MxPage-0.3.2-windows-x64.zip` |
| macOS Apple Silicon | `MxPage-0.3.2-macos-arm64.zip` |
| macOS Intel | `MxPage-0.3.2-macos-x64.zip` |

本版本保留已经完成的 Intel Mac 包；后续桌面版仅构建 Windows x64 和 macOS Apple Silicon。

完整解压到新目录后启动；macOS 可将应用移到“应用程序”。升级前建议在“设置 → 数据管理”创建备份。此版本不新增数据库迁移，已有任务继续使用原快照。

发布流水线先运行模拟回归、类型检查和浏览器流程测试，再在三个对应系统上打包。每个平台使用打包后的 Electron 运行时检查空数据库迁移、Prisma/sharp 原生模块、Agent 驱动加载、主要页面及项目创建与更新；同时检查包内没有开发数据和密钥。全部成功后才发布三个 ZIP 和 `SHA256SUMS.txt`。

上述自动运行检查不等同于桌面 Agent 对第三方软件的真实 GUI 操作验收；该能力仍按原有权限和验收状态开放。安装包无商业代码签名或 Apple 公证。

此前版本的详情页提示词统一确认、恢复规则及桌面构建说明见 [v0.3.1 发布记录](https://github.com/ziguishian/MxPage/blob/v0.3.2/docs/releases/v0.3.1.md)。本次打包验收使用临时数据库和模拟上游，不额外调用付费模型。
