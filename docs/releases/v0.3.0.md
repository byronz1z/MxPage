# MxPage v0.3.0

完整工作流重构与跨平台绿色版发布。

## 下载

| 文件 | 系统 |
| --- | --- |
| `MxPage-0.3.0-windows-x64.zip` | Windows x64，完整解压运行 `MxPage.exe` |
| `MxPage-0.3.0-macos-arm64.zip` | Apple Silicon Mac，解压打开 `MxPage.app` |
| `MxPage-0.3.0-macos-x64.zip` | Intel Mac，解压打开 `MxPage.app` |
| `SHA256SUMS.txt` | 三个压缩包的 SHA256 校验值 |

免安装、内置运行环境，不含开发者数据库、API Key、测试任务和生成记录。macOS 使用 ad-hoc 签名，未做 Apple 公证；Windows 未做商业代码签名，系统可能显示未知发布者提示。

## 核心变化

- 删除 `@openai/agents` 和 Runner，改用 V4 状态机与单次结构化 JSON 请求；继续使用现有 Provider、SQLite 模型、API 路径和图片存储。
- 重做断点恢复、停止收尾、心跳与请求账本，复用已完成的图片；可能计费的超时请求不自动重试。
- 先识别后跳转；补充信息逐题弹窗，三个具体推测答案加自行填写，保留确认及来源记录。
- 内容覆盖和排版本地容错，允许自然润色，保留已知参数、表格、数字和单位。质检绑定图片版本，问题图片保留，不自动付费重画。
- 图片并发上限 2，大套图分组检查；独立固定提示词批量翻译，不调用规划 Agent。
- 全局任务队列、失败查看、任务历史，以及文本、每张图片和检查耗时。
- 手机样机、iPhone 状态栏、轮播缓动，全图波浪波点加载和居中文字。
- 作品分类/翻页、头像和用户名、最近 12 个月热力图、设置侧栏、合并探测与模型能力颜色分组。
- API 费用/稳定性图表、可调计费规则、人民币展示与 GPT Image 输出估算。
- 更新中英文 README、AGENTS.md、llms.txt、公开首页 SEO 与隐私页面索引策略。
- 原生 Windows、macOS ARM64、Intel 自动构建和空白数据冒烟，发布校验文件。

## 升级

退出旧应用、备份数据后替换程序文件。桌面数据位于 `%APPDATA%/MxPage/`（Windows）或 `~/Library/Application Support/MxPage/`（macOS）；源码部署按环境配置备份。桌面与普通浏览器的 Key 存储独立。

新详情任务为 `workflowVersion: 4`。旧工作流只保留查看/导出，不自动迁移；需要新流程时创建新任务。当前详情流程要求探测到 GPT-6 Luna 与 GPT Image 2.5 Flare，不自动替换为日期版本，模型服务和额度由用户提供。

## 验证范围

测试覆盖恢复、停止、租约、并发、明确重试、结构化请求、补充问答、排版、翻译、计费、队列和图片状态。全部使用隔离数据与模拟 Provider，不产生真实模型费用。

桌面包在对应原生系统验证空白数据库迁移、Prisma/sharp 本机二进制、本地服务，以及首页、翻译、小红书、作品、任务、设置、监控、文档路由。自动冒烟不等于所有系统版本的完整人工 GUI 验收，详细日志见对应 GitHub Actions。

模型输出、翻译、推测参数和营销说法仍需人工核对；停止不能撤销 Provider 已收到的请求，也不能保证免费。费用监控为接口记录或估算，人民币使用设置汇率，最终以 Provider 账单为准。
