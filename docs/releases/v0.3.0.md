# MxPage v0.3.0

完整工作流重构与跨平台绿色版发布。

## 仓库发现与文档补充（2026-10-20，源码更新）

- 中英文首页增加按任务查入口、直接下载与案例链接、常见问题，集中解释费用、模型兼容、数据流向和恢复行为。`llms.txt` 同步短答案与实测来源，区分源码更新和已发布安装包。
- 修正公开域名配置导致个人首页可索引的问题：`/`、`/agent` 及其他工作区保持 noindex，站点地图不暴露任务页面；公开域名仅开放静态 `/llms.txt` 抓取。没有新增依赖或虚构 SEO 评分、评价与排名承诺。见[检索信息维护](../repository-discovery.md)。

## 稳定性优化补充（2026-10-19）

- 商品识别等业务入口缺少浏览器密钥时返回明确的 400 配置错误，修复英文异常被隐藏成通用 500 的问题；商品配置页引导配置密钥，缺少密钥不发送模型请求、不创建不确定调用记录。
- 修复 Gemini Image / Nano Banana 被识别为只能生成、无法用于编辑和翻译的问题，使用已有 generateContent 图片加指令路径；不推断蒙版能力，不添加目录外模型。
- Gemini 生图记录图片输出数量，服务状态识别既有实际生图操作；文本、识图及连接探测不计入图像验证。
- 修复真实验收发现的小红书任务误用默认 4+6 数量的问题：新任务冻结明确的 1–8 张竖版配图数量（默认5张），独立规划并保存发布标题、正文和标签；恢复使用原检查点，不重写历史任务数量。
- 详情任务规划阶段的进度总数优先读取任务快照，批量 0+1 不再误显示 0/10。
- Agent 文档导出返回实际下载 URL；旧消息中本会话成果的内部路径映射到下载入口，避免点击回复链接进入不存在的页面。计划字段明确图像数量不包含文档。
- 主图最低数量也降至 0，允许只生成详情图；页面、单任务、批量、Agent 及输出配置均禁止 0+0，合并保存时也校验总数，防止并发或部分更新绕过限制。
- 详情图最低数量降至 0，支持只生成主图；统一单商品、批量、Agent、手动规划与导出配置，修正保存或重新生成时把 0 还原成默认数量的问题。
- 模型发现区分本地缺少密钥与上游 401/403；鉴权失败不切端点或重试。失败刷新/保存不覆盖浏览器凭据，切换不同服务地址时清空旧密钥，避免错配。
- 修正 CloseAI 根地址的新原生协议检查：Claude/Gemini 使用文档规定的前缀并纳入缓存、任务快照和监控。旧快照保持原路径，GPT Image 的标准 Images 路径不变；模拟验证不代表账号目录或真实接口已验收。
- 设置新增“仅刷新模型列表”，读取并保存目录后不执行模型连接检查，保留仍有效的默认选择；说明平台价格页与当前密钥目录的区别。GPT Image 能力识别支持带供应商前缀的原始 ID。
- 任务队列区分失败、待查询和结果未确认；新单图、编辑、单图翻译、小红书图片保存恢复描述与异步编号。查询只读取原任务，重复操作复用结果，迟到图片不覆盖新版本。
- 图像设置按已知接口参数限制选项，展示文档依据、成功调用证据、参考图上限和蒙版能力；未知接口继续保留原兼容选项。
- Agent 新增可选金额预算、事务预留、实报/估算/未知费用展示与明确追加入口。达到限制停止新请求，已有请求收尾。估算不等于服务商硬性扣费上限。
- 监控最近记录改为文件尾读取，已确认图像路由避免历史扫描，详情页与任务记录隐藏时暂停轮询、空闲时降低频率。
- `lint` 改为实际 TypeScript 静态检查；业务 CI 增加 Windows 与两种 macOS 架构。没有新增依赖。
- 自动化验收仍仅使用模拟接口。2026-10-20 获得另行授权后补充 CloseAI 与 EvoLink 真实模型调用，具体操作和剩余验收项见[真实验收范围](../provider-live-acceptance.md)。跨平台 CI 配置不等于真实桌面验收。[详细边界与复验](../optimization-acceptance.md)。
- 修复 EvoLink 未描述的 Gemini 图像型号凭名称误选代理路径：新操作在上传或生图前校验接口描述，保留已成功路由、明确端点和旧快照。设置页明确显示旧配置中不同的主图/详情图模型，可主动统一；修正“自动修正一次”的过时提示，质检警告不会自动付费重画。

## 核心变化

- 将自动兼容扩展到 Responses、Chat Completions、Anthropic Messages、Gemini 原生文本/识图与 Agent 原生工具调用；普通文本支持四种协议的 JSON/SSE，原生 Agent 保留工具签名并按完整响应发送事件。无需手动选协议，已验证配置继续复用。
- 图像按每模型的接口描述选择标准 Images、Gemini 或 EvoLink 异步路径，不再只支持两个型号。EvoLink 覆盖 GPT Image、Seedream、Nano Banana、Qwen Image 等通用系列，分别转换质量、尺寸与参考图限制；特殊操作提前拒绝。成功路径优先，新快照保存协议与参数合同，旧快照保留旧路由，刷新模型目录不丢失兼容结果。补充无付费请求的模拟回归。

- 修复 EvoLink 图像请求误走 `/images/edits` 导致整批中断：官方地址自动使用参考图上传、`/images/generations` 异步提交和 `/tasks/{id}` 查询，保留原始模型 ID。详情页与批量翻译检查点持久化上游任务编号，查询断连后继续不重发；新任务快照保存图像协议。404/405 停止后续调度，不再误报“仅支持 Responses 图像工具”。监控记录协议、端点、上游任务编号；模拟测试覆盖恢复和停止，真实调用范围单独记录。

- 商品规划等待完整响应的上限从 60 秒延长至 180 秒，避免较慢的 Responses 流在刚开始响应后就被过早中止。本机等待超时显示具体上限；不确定请求仍需明确重试，不自动重发。

- 修复补充信息反复要求生成候选：尺码表题目中的统一单位可用于校验，并随选中答案保留；读取旧任务时重新校验已有候选，不重写历史或触发模型调用。真正不完整的候选显示具体原因。

- 新增独立 `/agent` 工作台和 `/settings/agent`：LangGraph.js + Deep Agents、三栏会话、整批方案确认、SQLite 检查点、幂等提交和 SSE 补读、受控工具、文件预览与导出。V4 固定工作流保持独立。
- Agent 工具调用单独验证，官方 Responses 优先、明确拒绝时自动兼容；保存原始模型 ID 与任务快照，禁止业务失败后的隐式重试/换模。已完成调用复用，未知调用需显式处理。
- 接入搜索、现有商品创作、文件处理、可选 Docker、MCP、技能及 Electron 私有桌面桥。桌面控制默认关闭：Windows 真实输入保存验收未通过焦点检查，macOS 两架构未实测，不能将构建通过当作双平台功能验收。见 [完整说明与验收记录](../agent-workspace.md)。

- 上传原图和断点分开保存，兼容旧 IndexedDB 草稿，避免每张上传都重写整套图片。作品卡片使用可重建的 WebP 缩略图，保留原图与结果。浏览器验收进入正式测试目录，增加 `test:browser` / `test:all`，PR 与发布 CI 均执行完整回归。

- 新增数据管理：显示数据位置，保存数据库与素材校验备份，预览后增量恢复缺失作品；恢复前自动备份，不覆盖已有修改。删除改为进入可还原回收站，保留原图、结果和版本。普通图片限制 20MB / 4000 万像素，批量总量 300MB，服务端校验真实格式和图片完整性。见[数据管理](../data-management.md)。

- 翻译结果完成后停止定时轮询，切回页面时同步；全局队列空闲检查降为 30 秒，隐藏页面暂停。作品封面优先使用当前选中的译图或生成结果，无结果时回退原图，保留原图对照及全部已有素材。

- 删除 `@openai/agents` 和 Runner，改用 V4 状态机与单次结构化 JSON 请求；继续使用现有 Provider、SQLite 模型、API 路径和图片存储。
- 重做断点恢复、停止收尾、心跳与请求账本，复用已完成的图片；可能计费的超时请求不自动重试。
- 先识别后跳转；补充信息逐题弹窗，三个具体推测答案加自行填写，保留确认及来源记录。
- 内容覆盖和排版本地容错，允许自然润色，保留已知参数、表格、数字和单位。质检绑定图片版本，问题图片保留，不自动付费重画。
- 图片并发上限 2，大套图分组检查；独立固定提示词批量翻译，不调用规划 Agent。
- 翻译提交后进入独立进度与预览页；单张、多张和文件夹上传按每套每种语言保存一份结果，不再额外创建原图作品。旧批次链接和恢复行为保留。
- 作品列表隐藏已有关联结果的旧翻译纯原图项目，分类计数同步排除；保留全部记录、文件及原图对照。
- 翻译草稿与详情页配置入口分离；原图上传支持浏览器本地断点恢复，项目与素材请求防重复。重复启动会复用当前项目服务，端口冲突明确报错，不再自动换端口或删除运行中的缓存。
- 全局任务队列、失败查看、任务历史，以及文本、每张图片和检查耗时。
- 手机样机、iPhone 状态栏、轮播缓动，全图波浪波点加载和居中文字。
- 作品分类/翻页、头像和用户名、最近 12 个月热力图、设置侧栏、合并探测与模型能力颜色分组。
- API 费用/稳定性图表、可调计费规则、人民币展示与 GPT Image 输出估算。
- 更新中英文 README、AGENTS.md、llms.txt、公开首页 SEO 与隐私页面索引策略。
- 原生 Windows、macOS ARM64、Intel 自动构建和空白数据冒烟，发布校验文件。

## 升级

退出旧应用、备份数据后替换程序文件。桌面数据位于 `%APPDATA%/MxPage/`（Windows）或 `~/Library/Application Support/MxPage/`（macOS）；源码部署按环境配置备份。桌面与普通浏览器的 Key 存储独立。

新详情任务为 `workflowVersion: 4`。旧工作流只保留查看/导出，不自动迁移；需要新流程时创建新任务。详情流程按已保存的角色默认模型执行，新任务保存模型与协议快照，已有任务恢复保留原选择。模型服务和额度由用户提供。

## 验证范围

测试覆盖恢复、停止、租约、并发、明确重试、结构化请求、补充问答、排版、翻译、计费、队列和图片状态。全部使用隔离数据与模拟 Provider，不产生真实模型费用。

桌面包在对应原生系统验证空白数据库迁移、Prisma/sharp 本机二进制、本地服务，以及首页、翻译、小红书、作品、任务、设置、监控、文档路由。自动冒烟不等于所有系统版本的完整人工 GUI 验收，详细日志见对应 GitHub Actions。

模型输出、翻译、推测参数和营销说法仍需人工核对；停止不能撤销 Provider 已收到的请求，也不能保证免费。费用监控为接口记录或估算，人民币使用设置汇率，最终以 Provider 账单为准。

## 2026-10-19 模型设置修复

- 修复模型选择未保存、文本与图像被测试模型锁定的问题；角色默认值自动保存，失败回退，不再注入未发现的预设模型。
- 文本与识图优先官方 Responses + 严格 JSON Schema；自动探测中转站的 Chat Completions 与 JSON 兼容格式，取消手动协议/模式选项。按模型保存检测结果，正式请求失败不隐式重发。
- 批量、翻译与 V4 恢复保留模型和协议快照；监控区分请求模型和上游返回模型。
- 升级需生成 Prisma 客户端并执行增量迁移，详见[兼容说明](../provider-compatibility.md)。
