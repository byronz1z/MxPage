# 全局任务队列

- 根布局挂载一个队列，覆盖详情页、批量详情页、翻译、小红书、图片修改、商品识别、导出等任务。只显示进行中、失败、中断、部分完成或等待补充信息的任务，运行任务优先。成功完成及没有失败项的已取消任务自动隐藏，作品和任务记录不删除。
- `GET /api/tasks/queue` 只读汇总 GenerationTask 和 DetailRun：所有运行任务及最近 7 天各最多 40 条结束记录，先合并批量父子任务再过滤成功记录。浏览器同步请求与翻译上传队列使用相同显示规则。不将提示词、图片内容或 Provider 配置返回浏览器。
- 已有翻译队列继续负责上传、暂停和用户明确发起的恢复。无数据库任务的商品初步识别与小红书同步请求由全局 fetch 桥记录，不读取请求正文，不重发请求。
- 初始收起为 44 × 44、16px 圆角入口，与桌面侧栏底部均距视口 20px。新任务开始展开；手动收起后轮询不打扰；全部执行结束后自动收起，失败及待处理任务仍可打开查看。
- 切换页面不销毁队列。刷新后从数据库/本地记录恢复；刷新中断的同步请求标记中断，不自动重试计费请求。已过期的工作租约只在队列中显示中断，不修改原运行记录。
- 记录上的移除按钮只隐藏队列记录，不删除作品。完整作品保留在“我的作品”。

验证：`node --import tsx --test tests/task-queue.test.ts tests/translation-queue.test.ts`，另运行 TypeScript 检查并在浏览器验证底部对齐、折叠状态、跨页面记录与结果入口。
