# Agent 工作台

`/agent` 是独立于一键详情页 V4 的通用工作台。导航位于“一键详情页”上方，设置位于 `/settings/agent`。中文界面复用现有组件；宽屏显示会话、对话、计划与成果三栏，窄屏通过抽屉打开侧栏。

## 使用流程

1. 在 API 配置中保存服务与文本模型。会话也可单独选择模型，服务发现的模型 ID 原样发送。
2. 输入任务或上传素材。普通聊天直接回答；执行任务先展示目标、步骤、工具、文件、生成数量、应用、目录、权限和预计费用，无法可靠计算费用时显示未知。
3. 确认一次后自动执行批准范围内的任务。增加工具、资源或生成数量时重新确认。
4. 运行中可暂停、继续和停止。停止阻止新请求，已发出的请求保留结果；断线只补读执行事件，不重新提交任务。
5. 成果面板提供图片、文档文字预览、原文件下载和已有作品入口。会话可重命名、归档和删除；删除会话不删除已保存到“我的作品”的项目。

默认每任务 30 次模型调用、100 次工具调用，达到预算后暂停，可明确追加一轮。内部规划、草稿和子 Agent 调用也计入预算。方案中的图片数量单独限制，显式重试可能消耗新额度。

## 框架与模型

- 固定 `deepagents@1.15.1`、`@langchain/langgraph@1.4.10`、`@langchain/openai@1.6.2`。一个主 Agent，研究、文件、创作三个受限子 Agent；图执行并发最多 2，电脑控制串行。
- Deep Agents 提供规划、虚拟草稿文件和上下文整理。LangGraph 管理中断与恢复，`BaseCheckpointSaver` 将检查点及 pending writes 写入同一 Prisma SQLite 数据库。不要求 LangSmith 云服务或另一个原生 SQLite 模块。
- 原生工具调用能力独立验证，不能把结构化 JSON 探测当作工具能力。轻量探测优先 Responses，Anthropic/Google 官方地址优先原生格式；仅遇到明确不支持的接口/流式参数时继续兼容检查。支持 Chat、Responses、Messages 和 Gemini，用户不需要选择协议。
- 使用协议专用客户端，防止 SDK 根据模型名称改协议。SDK 自动重试关闭；分词估算完全本地，不下载编码表。监控只采用上游实际 usage，不把本地估算当作账单。
- 每个任务固定模型、协议、工具集合、MCP 定义摘要、设置和批准方案。修改设置只影响新任务，恢复沿用原快照。模型不支持工具或视觉时明确报错，不静默换模。
- 四种协议均支持图片输入。Chat/Responses 保留 SSE；Messages/Gemini 的 Agent 请求使用完整 JSON，完成后发送文本事件，并保留工具结果及 Gemini 不透明签名供恢复使用。工具截图转换为后续视觉消息。断流缺少完成标记、空响应或无效工具调用进入“结果待确认”，不自动切协议或重发。
- 未知请求必须明确选择重试。电脑和浏览器点击/输入不能重放，需停止原任务并新建任务重新观察。

官方框架说明：[LangGraph](https://docs.langchain.com/oss/javascript/langgraph/overview)、[Deep Agents](https://docs.langchain.com/oss/javascript/deepagents/overview)。选择依据是扩展性，并不宣称存在所有场景的“最强框架”。

## 能力与配置

| 能力 | 使用条件与边界 |
| --- | --- |
| 联网搜索 | 自动模式优先已验证原生搜索，否则使用 Tavily。设置中的验证按钮会发送一次真实搜索请求，可能计费；必须返回实际搜索调用及来源注解才启用。无服务时明确提示。 |
| 公开网页 | 读取 HTTP(S) 网页并返回来源，拒绝本机、内网、元数据地址及重定向越界；限制时间与体积，不执行网页脚本。 |
| 文件 | 读取图片、TXT、MD、CSV、PDF、DOCX、XLSX；导出 MD、CSV、PDF、DOCX、XLSX。单文件 25MB，限制 Office 展开体积，PDF 最多 100 页，文字最多 8 万字符。扫描 PDF 不内置 OCR。中文 PDF 使用随包 OFL Noto Sans SC 字体。 |
| 创作 | 商品识别、V4 详情页/小红书、单图生成/重生成/编辑/翻译、批量翻译、作品 ZIP。调用原服务和任务队列，不改变 V4 检查点、计费及重试语义。 |
| 沙箱 | 默认关闭，需要已安装 Docker 和可信 Python/Node 镜像。批准附件以副本提供，仅挂载本次目录；无网络、只读系统、非 root、256MB、1 CPU、64 进程、60 秒、单文件 25MB。不自动拉取镜像，不运行宿主机 Shell。 |
| MCP | 设置中显式配置 HTTPS 服务；桌面版支持受控 stdio，参数不经过 Shell。工具定义改变时旧任务暂停。只添加可信服务，服务本身的权限由部署者负责。桌面重启后本地 MCP 需重新保存注册。 |
| 技能 | 将可信 `SKILL.md` 放入数据目录 `agent-skills/<id>/` 并启用。技能指导已批准工具，不安装扩展、不扩大权限。 |

网页、文件和 MCP 输出均视为资料。代码检查批准工具、资源 ID、数量、目录与应用；会话路径拒绝越界及符号链接。当前是单用户部署，不是具备多人身份隔离的公共服务。

## 桌面控制与平台状态

固定 `@zavora-ai/computer-use-mcp@7.6.1`，通过独立子进程 stdio 接入。Electron 验证工作台窗口、主 frame、来源与已登记方案摘要；普通网页 API 不能授予本机控制权限。仅开放控件、截图、点击、输入、快捷键、窗口等允许工具，不开放任意 Shell。

网页操作使用 Playwright 专用配置目录，需要系统安装 Chrome/Edge，不连接已有浏览器标签。软件操作优先可访问性控件。一次只有一个任务持有电脑锁；暂停恢复需重新观察。焦点变化、用户接管或权限拒绝时阻止操作，`Ctrl/⌘ + Shift + Esc` 撤销授权并停止调度，任务退出也释放授权。

GUI 共享真实用户桌面，目录检查属于操作约束，不构成操作系统沙箱。macOS 需辅助功能、屏幕录制和必要的输入监控权限；Windows 需交互桌面，不自动提权。

### 实机验收记录（2026-10-19）

| 平台 | 结果 |
| --- | --- |
| Windows x64 | 原生加载、MCP 工具发现、测试窗口发现与控件读取通过。窗口激活失败，严格焦点保护阻止输入；后续尝试还遇到现有控制锁，未抢占。**输入→保存→验证链路未通过验收**，没有绕过保护。 |

桌面控制默认关闭。编译、驱动加载和打包成功不能代替 GUI 验收；在三个目标的记录补齐前，不宣称该功能已完成双平台交付。

## 持久化与接口

增量迁移新增会话、消息、任务、事件、调用记录、成果、设置、检查点和 pending writes。文件位于 `STORAGE_ROOT/agent/<sessionId>/`。现有备份包含这些表和文件；恢复不覆盖已有会话，未完成任务不会自动执行。缺少 Agent 表的旧备份仍可恢复原作品。

API、Tavily、MCP Key 保存在浏览器和运行期间内存，不进入数据库、任务、消息或日志。重启后恢复需要重新取得浏览器凭据。前端显示执行摘要、工具状态与来源，不展示内部推理。

- `/api/agent/sessions`、`[id]`：会话管理。
- `/api/agent/sessions/[id]/messages`、`files`：幂等提交和附件。
- `/api/agent/runs/[id]`：确认、暂停、继续、停止、补充信息。
- `/api/agent/runs/[id]/events`：带单调序号的 SSE；支持 `Last-Event-ID` / `after`，只补读。
- `/api/agent/artifacts/[id]`、`preview`：下载及预览。
- `/api/agent/settings`、`verify-search`：配置与独立搜索验证。

工具先登记后执行，完成结果复用，未知结果不隐式重发。主 Agent 草稿是图状态，不能直接访问宿主机文件。

## 开发验收

```sh
npm run test:agent
npm run test:agent:browser
npm run typecheck
npm test
npm run build:desktop
npm run check:agent-driver
# 仅在相应平台的真实交互桌面操作临时测试应用
npm run test:agent:desktop
```

自动测试使用模拟模型、模拟搜索、临时数据库和存储，不调用付费服务。浏览器覆盖导航、刷新确认、下载、重命名、手机抽屉及设置，截图位于忽略目录 `test-output/agent-browser/`。原生脚本通过后输出 `test-output/agent-native/<platform>-<arch>.json`，失败返回非零。

本次已通过：347 项完整自动测试（其中 20 项 Agent 测试）、类型检查、Agent 浏览器验收（含文档预览）、原有翻译/数据管理浏览器回归、Windows 桌面构建/本地打包及打包后的页面与原生加载冒烟测试。商品工具模拟验收实际创建作品，生成并编辑图像，验证快照模型 ID 与生成数量限制；Responses 和 Chat 的流式测试均通过，不调用真实付费模型。

真实 Tavily、第三方 MCP、Docker 和具体中转站仍需按部署环境验证。正式公开部署或发布前需继续处理上游依赖安全审计；功能测试不能替代依赖审计。
